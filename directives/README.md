# Directives (Layer 1)

This directory contains Standard Operating Procedures (SOPs) for the AI Agents.
Each directive should follow this structure:

1. **Goal**: What are we trying to achieve?
2. **Inputs**: What data is needed?
3. **Execution**: Which script in `execution/` should be used?
4. **Logic**: Step-by-step decision process.
5. **Edge Cases**: How to handle common failure modes.
6. **Output**: What is the final result?

## Current Directives

- `update_weather.md`: Service for keeping the dashboard fresh.
- `categorize_knowledge.md`: Logic for organizing the KB.
