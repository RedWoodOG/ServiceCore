# News Feed Images

This folder contains placeholder images for the Industry Briefing news feed.

## Required Images

Place the following images in this directory:

1. **news_factory.jpg** - Factory/manufacturing image (for Fenco Solutions article)
   - Suggested: High-tech factory floor, manufacturing equipment, or Fenco logo
   - Dimensions: 300x220px or larger (16:9 aspect ratio recommended)

2. **news_vault.jpg** - Bank vault image (for American Vault article)
   - Suggested: Massive vault door, security equipment, or American Vault logo
   - Dimensions: 160x220px or larger (3:4 aspect ratio recommended)

3. **news_kisan.jpg** - Currency counter image (for Kisan Electronics article)
   - Suggested: Bill counter machine, currency sorting equipment, or Kisan logo
   - Dimensions: 160x220px or larger (3:4 aspect ratio recommended)

4. **news_hyosung.jpg** - ATM/equipment image (for Hyosung America article)
   - Suggested: ATM machine, banking equipment, or Hyosung logo
   - Dimensions: 160x220px or larger (3:4 aspect ratio recommended)

5. **news_finance.jpg** - Financial/banking image (for Industry Watch article)
   - Suggested: Banking equipment, financial charts, or generic banking imagery
   - Dimensions: 160x220px or larger (3:4 aspect ratio recommended)

## Fallback Behavior

If images are missing, the app will display a grey gradient background with a newspaper icon as a placeholder. This ensures the app works even without images.

## Logo Sources

You can find logos for:
- **Fenco Solutions**: Search for "Fenco Solutions logo"
- **American Vault**: Search for "American Vault logo"
- **Kisan Electronics**: Search for "Kisan Electronics logo" or "Kisan currency counter"
- **Hyosung America**: Search for "Hyosung ATM logo" or "Hyosung America logo"

## Quick Setup

1. Download or create images matching the names above
2. Place them in this `assets/images/` folder
3. Run `flutter pub get` to refresh assets
4. Hot restart the app to see the images
